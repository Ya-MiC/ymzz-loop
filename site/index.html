準時的提醒

在你選的時區與時間，寄一封附今日頁面連結的信。

📊

Sheet + Git 歷史

昨天的內容進 Google Sheet 方便做圖，也以 Markdown 存進倉庫，永久可追溯。

🌏

任意時區

預設首爾 07:00。設兩個 repo Variables 就換成你的，檔名也帶時區。

🧩

可插拔同步端

要接 Obsidian、Telegram、CSV？放一個實作 { name, enabled, write } 的檔案即可。

運作方式

  1. ⓪

    每小時閘門

    每小時醒來，不到時間或今天已執行就數秒結束。

  2. ①

    Notion 建頁

    建好今天含 ①–⑩ 段落的空白頁。

  3. ②

    寄信

    直接連到今天的頁面。

  4. ③

    同步昨天

    Sinks：Google Sheet + Markdown。

  5. ④

    提交與紀錄

    快照提交，Notion 同步紀錄追加一行。
