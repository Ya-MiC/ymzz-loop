Your first review, in about 10 minutes.

Fork the automation — the product branch only — add your secrets, turn GitHub Actions on, and open today’s blank Notion page from the reminder email.

Do not fork or copy the showcase website (the main branch / site/ folder). The product branch is the template.

Before you begin

What you need

  1. A GitHub account (your fork runs the loop)
  2. A Notion workspace you can connect an integration to
  3. A Google account for Sheets, plus Gmail if you want the reminder email
  4. About 10 minutes for the first setup

  1. 01 · about 2 min

    Take the product branch, not the website

    Open the product branch, download or clone it, and push that tree to your own empty repository as main. GitHub’s “Use this template” or a fork of main copies the showcase site — skip those if you only want the automation.

    git clone --depth 1 --branch product --single-branch https://github.com/Ya-MiC/ymzz-loop.git
cd ymzz-loop
# Push this tree to YOUR empty repository as main

    Open the product branch

  2. 02 · about 3 min

    Connect Notion and run setup once

    Create an internal Notion integration named ymzz, share your review page with it, then run setup to create the databases and commit sync.config.json.

    NOTION_TOKEN=<token> ./setup.sh "https://www.notion.so/<your-page>"
git add sync.config.json && git commit -m "setup ids" && git push

  3. 03 · about 3 min

    Sheet + mailbox

    Create a Google Sheet, share it with your service-account email (Editor), and create a Gmail app password if you want email reminders.

  4. 04 · about 1 min

    Secrets, then turn Actions on

    Add the repository secrets below. Then open Actions and allow workflows on your fork. Without this step the schedule never runs.

    Required secrets

    Required secrets
    Secret
    NOTION_TOKENNotion integration token
    GOOGLE_SERVICE_ACCOUNT_JSONThe whole service-account JSON file
    SHEET_IDSpreadsheet ID from /d/SHEET_ID/edit
    SMTP_USERYour Gmail address
    SMTP_PASS16-character app password
    MAIL_TOWhere reminders should arrive

    Optional SMTP_HOST / SMTP_PORT — defaults: smtp.gmail.com / 465

    Optional Variables (not secrets): YMZZ_TZ and YMZZ_REMIND_TIME

  5. 05 · about 1 min

    Run once, open the email, write

    Actions → daily-review → Run workflow. You should get today’s Notion link by email (if SMTP secrets are set), a new page in Notion, and two tabs in the Sheet. That page is your first review.

Where data stays

Your reviews stay in accounts you control

Each successful run writes in your Notion, appends yesterday to your Google Sheet, and commits Markdown under notion/YYYY/ in your fork. This showcase site does not store your reviews. Demo to-dos on the homepage live only in this browser for 60 hours.

Email reminder

Mail is sent from your SMTP, not a hosted inbox

When SMTP_USER, SMTP_PASS and MAIL_TO are set, the workflow emails you today’s Notion link after the page is created. If those secrets are missing, the reminder step is skipped and the rest of the loop can still run. Failure and end-of-chapter notices use the same hook.
