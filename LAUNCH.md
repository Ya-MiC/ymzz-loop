## 4. Show HN（https://news.ycombinator.com/submit）

**Title**  
Show HN: ymzz-loop – open-source daily review loop (Notion→Sheets+Git, 600-day chapter)

**Body**  
Hi HN — I built ymzz-loop because a day you never review is a day you don’t get back.

It is a static-product + GitHub Actions template you fork:
1. Each day at your time, it creates a blank review page in Notion and emails the link.
2. Next run auto-ingests yesterday into Google Sheets and Markdown in your fork (optional Feishu Bitable).
3. One deploy is a 600-day chapter. The counter goes 600→0 as a gentle clock; at 0 the daily loop pauses and you close with a 600-day summary. Redeploy for the next chapter. It is a chapter ending with a summary, not destruction.

Why not Day One / Notion+Zapier / Obsidian DIY?
- Day One is a lovely journal, not a Notion→Sheets+Git multi-end loop you own.
- Zapier is metered glue; this is $0 self-host on free Actions.
- Obsidian DIY can be wired up, but is not turnkey with email + Sheets + holdings + optional Feishu.

MIT code. No AI quota. Any time zone. $0/month.

Repo: https://github.com/Ya-MiC/ymzz-loop
Site + 10-min start guide: https://ya-mic.github.io/ymzz-loop/start.html

Happy to answer setup questions. I would love feedback on whether the 600-day chapter helps you start today instead of “someday”.

每天在你选的时间：
- 在 Notion 建好今日空白复盘，并发邮件链接
