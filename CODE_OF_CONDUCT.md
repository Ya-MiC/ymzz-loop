# 行為準則 Code of Conduct

本專案採用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)。
This project follows the Contributor Covenant 2.1.

簡而言之 In short：友善、尊重、就事論事；不騷擾、不人身攻擊。Be kind, be respectful, critique ideas not people.

違規請寄信至維護者（見 [SECURITY.md](SECURITY.md) 的聯絡方式）。Report violations to the maintainer via the contact in SECURITY.md.
