## 第一次開啟

修之前：樣式把 `.app` 設成 grid，蓋過了 `hidden`，嚮導下面還看得到檔案頁。已在 `app/ui/app.css` 加上 `[hidden] { display: none !important; }`，並重拍六步。

空資料夾 `/tmp/ymzz-empty` 顯示「這裡沒有子資料夾。」字母電話停在第一步並寫出原因。完成後側欄是 `用戶5678`，彙報時區是「首爾」。

第 4 步的「開始準備」會呼叫本機辨識準備；「先跳過」不下載。這次截圖走的是跳過。

## 安裝與離線

視窗程式 `ymzz-bingce` 會啟動旁邊的 `ymzz-vibe`。核心檔不在時，視窗會停在「找不到本機核心」。頁面本身只向 `127.0.0.1` 要資料。沒有網路時，稱呼、資料夾和彙報仍可做；辨識模型若還沒準備，掃描圖片那一步會失敗，有文字的 PDF 不依賴那個下載。

草稿預發行裡已有 Windows `.msi` / `.exe`、macOS `.dmg`、Linux `.deb` / `.AppImage`。這些檔要登入 GitHub 才能從草稿下載。同一次工作流程也交出未簽名的 Android `.apk` 和 iOS 模擬器 `.app`。兩份都沒有本機核心 `ymzz-vibe`，所以不能打開彙報。沒有上架。

## 跳轉與窄螢幕

2026-11-10 在 Linux 上用核心和 Chromium 點過。彙報上的數字會換頁。沒有路徑輸入框。390 寬時側欄收成抽屜，底部有彙報、檔案、對話、文件、沙箱和「更多」。抽屜打開時用實色紙底，不會透出後面的字。導覽背景用的是已核准色票裡的 `--bg-0`，沒有新增色碼。

這次沒有用裝好的 Windows `.exe` 或 AppImage 點，也沒有跑 tauri-driver。手機殼仍然沒有核心。
