# License boundary

This file records ownership. It does not change `LICENSE`.

The repository `LICENSE` stays MIT for this round. MIT allows commercial use, modification, and distribution when the copyright and permission notices are kept. It does not prohibit a commercial contest entry.

Code already published under MIT, including ymzz-loop history and the vendored T3 Code modules, stays under those MIT notices. That history cannot be revoked from here. Third-party files keep the license in their own `LICENSE` or `NOTICE` files. This product does not relicense them.

New ymzz-vibe code written for this app can, in a later owner decision, use Apache-2.0 or another OSI license. That choice is not made in this commit, and it does not block the build. Apache-2.0 is a possible future license for own code only. It would still require keeping MIT notices on MIT files.

PaddleOCR is Apache-2.0 and is not bundled. Its weights are not downloaded, because no checksum is pinned. The wenrun design tokens used by the interface are copied as CSS variables for this app; the private design archive and the Ludi study corpus are not in this repository. The separate design-skill repository stays MIT and is not modified here.

A contest that wants a non-MIT license for newly written own code can choose that later, file by file, without deleting the MIT notices this tree already carries.
